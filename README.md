# infra-commercial-prop-ml
•  ML-driven analysis of how infrastructure factors (transport, logistics, amenities) impact commercial real estate valuation.

## Данные

Используется датасет **Sberbank Russian Housing Market** (Kaggle) — сделки по продаже жилья в Москве и области, 2011–2015 гг.

### Версионирование
Исходные данные разделены на `data/raw/sberbank_train_raw.csv` (60% записей, 2011–05.2014, файл неизменен после разбиения) и 4 порции «новых» данных в `data/incoming/batch_01.csv` … `batch_04.csv` (по времени, ~3 месяца каждая). Разбиение выполняется скриптом `scripts/split_data.py`.

Файлы добавлены в Git напрямую (без DVC/Git LFS): суммарный объём данных ~47 МБ, что не превышает разумные лимиты для учебного репозитория на GitHub. При дальнейшем росте объёма данных (например, подключении полного архива сделок) целесообразен переход на DVC.

### Сценарий обновления
Одна порция данных (`batch_0N.csv`) имитирует квартальную выгрузку новых зарегистрированных сделок (например, из Росреестра или агрегатора объявлений). Целевая переменная (`price_doc`, цена сделки) известна уже в момент поступления порции, так как в датасет попадают только завершённые сделки — в отличие от сценария с активными объявлениями, где цена продажи становится известна лишь после закрытия сделки.
