# 2.6. Пайплайн обработки данных и план признаков

## Таблица 4. Шаги пайплайна

| Шаг | Вход | Действие | Выход | Только при обучении? |
|---|---|---|---|---|
| Загрузка | Файл порции (CSV) | Чтение файла, приведение типов | Таблица исходных данных | Нет - общий шаг |
| Проверка качества | Таблица исходных данных | Проверка требований из 2.3 (табл. 1) | Отчёт о проверке, отфильтрованные данные | Нет - общий шаг |
| Очистка | Проверенные данные | Импутация пропусков, обрезка нереалистичных значений, флаг круглой цены | Очищенные данные | Нет - общий шаг (параметры вычисляются только при обучении) |
| Формирование признаков | Очищенные данные | Кодирование категориальных, построение новых признаков (табл. 5) | Таблица признаков | Нет - общий шаг (параметры вычисляются только при обучении) |
| Обучение модели | Таблица признаков (train) | Подбор гиперпараметров, обучение | Обученная модель | Да - только при обучении |
| Сохранение | Таблица признаков / модель | Запись в хранилище с версионированием | Сохранённые артефакты | Для данных - нет; для модели - да |

## Воспроизводимость

Запуск одной командой (python scripts/pipeline.py --input <файл>); фиксированный random_state; параметры очистки и формирования признаков (медианы импутации, границы выбросов, список категорий) вычисляются один раз на обучающей части (data/raw) и сохраняются, для новой порции только применяются - это гарантирует идентичную обработку и исключает утечку информации из новой порции в параметры трансформации.

## Таблица 5. План признаков

| Признак | Исходные данные | Преобразование | Гипотеза |
|---|---|---|---|
| dist_to_center | kremlin_km, sadovoe_km, ttk_km, bulvar_ring_km | Один репрезентативный признак вместо четырёх коррелирующих (r>0.99) | H1: удалённость от центра отрицательно влияет на цену (ρ=-0.321) |
| cafe_density_3000 | cafe_count_1500/2000/3000/5000 | Свести к одному показателю плотности кафе | H2: плотность кафе положительно влияет на цену (ρ=0.363) |
| build_age | build_year, timestamp | Год сделки минус год постройки | Знание предметной области: новое здание ликвиднее |
| floor_ratio | floor, max_floor | Отношение floor/max_floor | Знание предметной области: относительный этаж информативнее абсолютного |
| is_investment | product_type | Бинарное кодирование (Investment=1, OwnerOccupier=0) | H3: тип сделки значимо влияет на цену (p=1.83e-183) |
