# 2.5. Архитектура системы

## Логическая архитектура — компоненты системы

| Компонент | Назначение | Вход | Выход | В какой ПР реализуется |
|---|---|---|---|---|
| Приём данных (Data Ingestion) | Приём новой порции данных, первичное считывание файла | CSV-файл порции (data/incoming/batch_0N.csv) | Таблица исходных данных | Источники/инструментарий — ПР1; загрузчик и скрипт разбиения — ПР2 (2.1); полноценный сервис приёма — ПР3 |
| Хранилище (Storage) | Версионированное хранение исходных и поступающих данных | Файлы данных, история Git-коммитов | data/raw (неизменная часть), data/incoming (новые порции) | ПР2 (2.1) |
| Подготовка данных и признаков (Data & Feature Processing) | Проверка качества (табл. 1), очистка, формирование признаков (табл. 5) | Таблица исходных данных | Таблица признаков, отчёт о проверке качества | Спроектировано в ПР2 (2.3, 2.6); реализовано в ПР3 |
| ML-модуль (Model) | Обучение модели, получение предсказаний цены | Таблица признаков | Обученная модель, прогноз price_doc | ПР3 |
| Расчёт показателей (Metrics) | Пересчёт ключевых показателей (табл. 2) после каждой порции | Прогнозы модели, таблица признаков | Значения показателей, история по порциям | Показатели определены в ПР2 (2.3); расчёт реализован в ПР3 |
| Панель (Dashboard) | Отображение текущих значений показателей и их динамики | Значения показателей из хранилища | Визуализация (графики, таблицы) | Спроектировано в ПР2 (2.5); реализуется в ПР3 и далее |
| API | Выдача прогноза по запросу на основе признаков объекта | Признаки конкретного объекта | Прогнозная цена | Спроектировано в ПР2 (2.5); реализуется в ПР3 и далее |
