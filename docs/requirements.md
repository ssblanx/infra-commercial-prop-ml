# 2.4. Требования к системе

## Таблица 3. Требования к системе

| ID | Требование | Группа | Способ проверки |
|---|---|---|---|
| F-01 | Система принимает новую порцию данных в формате CSV с фиксированной схемой столбцов (data/incoming/batch_0N.csv) | Функциональное | Демонстрация |
| F-02 | После загрузки порции система выполняет проверку соответствия требованиям качества данных (табл. 1) | Функциональное | Демонстрация |

| F-04 | После успешной загрузки и проверки порции система пересчитывает ключевые показатели (табл. 2) | Функциональное | Демонстрация |
| F-05 | Панель отображает текущие значения показателей и их динамику по порциям | Функциональное | Демонстрация |
| F-06 | Система выдаёт прогноз цены объекта по запросу на основе его признаков | Функциональное | Демонстрация |
| N-01 | Обработка порции из ~3000 записей занимает не более 2 минут | Нефункциональное | Замер времени |

| N-04 | Доля ложных отклонений корректных записей при проверке качества не превышает 1% | Нефункциональное | Замер на контрольной выборке |
| N-05 | Повторный запуск пайплайна на тех же данных даёт идентичный результат (фиксированный random_state) | Нефункциональное | Демонстрация |
