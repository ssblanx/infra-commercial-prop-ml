# 2.3. Требования к качеству данных и ключевые показатели

## Таблица 1. Требования к качеству данных

| № | Признак(и) | Требование | Действие при нарушении |
|---|---|---|---|
| 1 | full_sq | Значение в диапазоне 10–300 кв.м | Запись исключается, предупреждение |
| 2 | life_sq, full_sq | life_sq ≤ full_sq | Запись исключается, предупреждение |
| 3 | floor, max_floor | floor ≤ max_floor | Запись помечается для ручной проверки, не используется при обучении |
| 4 | build_year | Диапазон 1860–текущий год либо пусто | Некорректное значение → NaN, запись не исключается |
| 5 | state | Значение ∈ {1,2,3,4} либо пусто | Некорректное значение → NaN, предупреждение |
| 6 | price_doc | Значение > 0 и ≤ 50 000 000 ₽ | Запись исключается из обучения, предупреждение |
| 7 | id | Значения уникальны | Порция не обрабатывается, эскалация на ручную проверку |

## Таблица 2. Ключевые показатели

| Показатель | Как рассчитывается | Использует модель | Решение |
|---|---|---|---|
| MAE/RMSE прогноза на новой порции | Сравнение прогноза с фактом на новых данных | Да | Нужно ли переобучать модель |
| Доля объектов с отклонением прогноза >15% | Доля записей за порогом отклонения | Да | Приоритизация объектов для ручной проверки |
| Медианная цена за кв.м по порции | price_doc / full_sq, медиана | Нет | Отслеживание рыночной динамики |
| Доля записей, не прошедших требования качества | Доля "забракованных" записей в порции | Нет | Нужно ли приостановить обработку порции |
